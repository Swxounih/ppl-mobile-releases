PPL Mobile is a cloud-based smart library application developed in partnership with the **Pangasinan Provincial Library**, located at Capitol Complex, Lingayen, Pangasinan.

The system provides patrons with a convenient platform to search the library catalog, manage their digital library accounts, request book borrowings, reserve materials, receive notifications, and access an AI-powered library assistant.

Developed as an undergraduate capstone project at Pangasinan State University – Lingayen Campus, PPL Mobile is implemented in collaboration with the Pangasinan Provincial Library and deployed at the library to support its digital transformation initiatives.

This repository serves as the distribution platform for the Android application releases.

## About PPL Mobile

PPL Mobile aims to improve the accessibility and efficiency of library operations by bringing essential library transactions and information closer to patrons through their Android devices.

Instead of relying entirely on traditional, on-site processes, patrons can access selected library functions digitally while library personnel manage operations through a centralized web-based management system.

The application is designed to provide a more accessible, organized, and technology-driven library experience.

---

## Key Features

- **Book Catalog** – Search and browse library materials and check their availability.
- **Digital Library Card** – Access a digital library card with a QR code, including an offline-saved copy.
- **Attendance Monitoring** – Record library visits through QR-based time-in and time-out.
- **QR-Based Borrowing** – Scan book QR codes to initiate borrowing requests.
- **Book Reservations** – Request reservations for library materials.
- **Borrowing Management** – View borrowing records, statuses, and due dates.
- **Favorites** – Save books for convenient access later.
- **Notifications** – Receive updates about borrowing requests, due dates, and library announcements.
- **Library Events** – View upcoming library activities and events.
- **AI Library Assistant** – Get assistance with library-related questions and book discovery.
- **Guest Browsing** – Explore the book catalog without creating an account.

---

## Part of the Smart Library Ecosystem

PPL Mobile is the patron-facing component of a larger centralized library management ecosystem developed for the Pangasinan Provincial Library.

The project consists of two interconnected applications:

| Application | Intended Users | Main Responsibilities |
|---|---|---|
| **PPL Mobile** | Library Patrons | Book catalog, digital library card, attendance, borrowing, reservations, favorites, notifications, and AI assistance |
| **PPL Web App** | Librarians and Library Staff | Borrowing approvals, inventory management, catalog administration, patron management, attendance monitoring, and reports |

Both applications share a centralized backend, allowing information and transactions to be synchronized across the system.

For example, a borrowing request submitted through PPL Mobile becomes available to authorized library personnel through the web application for processing and approval.

## Android Installation

1. Visit the [PPL Mobile Website](https://ppl-mobile.vercel.app) or the [GitHub Releases page](https://github.com/Swxounih/ppl-mobile-releases/releases).
2. Open the latest release.
3. Download the Android APK compatible with your device.
4. Open the downloaded APK.
5. If prompted, allow installation from your browser or file manager.
6. Complete the installation and launch PPL Mobile.

**Note:** Android may display a security warning because the application is distributed outside the Google Play Store.
